## Installation

Clone this repository and its submodules using:

`git clone --recurse-submodules https://github.com/GlassBrainLab/StoryCorps_Distribution.git`

## TAACO Submodule

The code in this repository depends on the **Tool for the Automatic Analysis of Cohesion (TAACO)** 
tool developed by collaborators at the Learner Corpus Research and Applied Data Science Lab at the 
University of Oregon and the Data Science Institute at Vanderbilt University. 
See https://www.linguisticanalysistools.org for more details.

The TAACO repository can be found at: https://github.com/LCR-ADS-Lab/TAACO/tree/main

TAACO is available for use under the Creative Commons Attribution-NonCommercial-Sharealike license (4.0).
For more information on this license, see: https://creativecommons.org/licenses/by-nc-sa/4.0
